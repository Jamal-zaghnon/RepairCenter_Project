# نظام إدارة مركز صيانة الأجهزة المنزلية

مشروع Console App بلغة C# يستهدف .NET Framework 4.7.2، ومقسم إلى ملفات ومجلدات مستقلة.

## طريقة الفتح
1. فك ضغط المجلد.
2. افتح `RepairCenter.sln` باستخدام Visual Studio.
3. اجعل `RepairCenter` مشروع بدء التشغيل إذا لم يكن محدداً.
4. شغّل باستخدام Ctrl+F5.

إذا لم يكن Developer Pack الخاص بـ .NET Framework 4.7.2 مثبتاً، يمكن تغيير Target Framework من خصائص المشروع إلى إصدار .NET Framework المثبت لديك.

## طريقة عمل البرنامج
- يحتوي البرنامج على ثلاثة أجهزة تجريبية جاهزة: شاشة (جاري الإصلاح)، ميكروويف (تم التصليح)، ومروحة (لم يبدأ إصلاحها).
- لا توجد قاعدة بيانات ولا حفظ دائم للبيانات؛ التغييرات تبقى أثناء تشغيل البرنامج فقط.
- يمكن عرض الأجهزة، تحديث حالة جهاز باستخدام رقمه التسلسلي، وعرض الإحصائيات.
- حالات الصيانة: لم يبدأ، جاري الإصلاح، تم التصليح.
- عند تغيير الحالة يتم إطلاق Event لإظهار إشعار.

## تكاليف الإصلاح التجريبية
التكلفة الإجمالية = تكلفة القطع + أجرة الصيانة الثابتة حسب نوع الجهاز:
- الشاشة: 50,000
- الميكروويف: 35,000
- المروحة: 20,000

هذه القيم للتجربة فقط ويمكن تعديلها داخل ملفات الأصناف الثلاثة.

## توزيع المفاهيم المطلوبة
- `Interfaces/IDevice.cs`: الواجهة المشتركة.
- `Models/Device.cs`: الصنف المجرد والخصائص المشتركة والتغليف والعدادات الساكنة والحدث.
- `Models/Television.cs`, `Microwave.cs`, `Fan.cs`: الوراثة وإعادة تعريف حساب تكلفة الإصلاح.
- `Enums/MaintenanceStatus.cs`: حالات الصيانة.
- `Delegates/StatusChangedHandler.cs`: تعريف Delegate الحدث.
- `Helpers/ValidationHelper.cs`: Static Class للتحقق من البيانات.
- `Services/RepairCenterManager.cs`: قائمة `List<Device>` وإدارة الأجهزة والاشتراك بالحدث وتعدد الأشكال.
- `Program.cs`: القائمة الرئيسية والتفاعل مع المستخدم.

## ملاحظة
تم اختيار .NET Framework 4.7.2 وكتابة الكود بأسلوب C# تقليدي مناسب لمشروع Console App في Visual Studio. لم يتم إجراء Build فعلي في بيئة الإنشاء الحالية لعدم توفر مترجم C# أو MSBuild فيها.
